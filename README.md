# ✨ NOVA — AI Shopping Agent

NOVA is a premium AI-powered shopping assistant designed to help users discover, compare, save, and purchase products through a simple and modern interface.

## 🖥️ Project Preview

![NOVA AI Shopping Agent](nova_home.png)

## 🚀 Features

- 🔎 Smart product search
- 🛍️ 800+ products
- 📱 Electronics
- 👕 Fashion
- 🎮 Gaming
- 🎧 Audio
- 💄 Beauty
- 🏠 Home products
- 📚 Books
- ⭐ Product ratings
- 💰 Budget-based product search
- ❤️ Save favourite products
- ⚖️ Compare products
- 🛒 Shopping cart
- 💳 Checkout system
- 📦 Order history
- 🔍 Search history
- 🎨 Premium responsive UI
